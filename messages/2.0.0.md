Breaking changes:

- The key used to override LSP-marksman settings in project settings has changed from `marksman` to `LSP-marksman`.
  If you use project-specific overrides for LSP-marksman, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "marksman": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-marksman": {
                  // ...
              }
          }
      }
  }
  ```
